# 🛑 Security Policy

The security of the DreamBees Hive and our community of creators is of the highest importance to us. We appreciate the efforts of security researchers to report vulnerabilities according to this policy, which coordinates our response and maintains the safety of our systems.

---

## 🛡️ Supported Versions

We provide security updates for the following versions shown below. 

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Yes             |
| < 1.0.x | ❌ No              |

---

## 🛰️ Reporting a Vulnerability

If you believe you have found a security vulnerability in DreamBees, please report it to us as soon as possible. 

### 🛑 DO NOT OPEN A PUBLIC ISSUE
Please do not open a public issue on GitHub for security-related matters. 

### ✅ How to Report
Please send an email to **security@dreambeesai.com** (placeholder) or contact a repository administrator privately via Discord. 

We aim to respond to all reports within 48-72 hours. Your report should include:
- A detailed description of the vulnerability.
- Steps to reproduce (PoC).
- Potential impact.
- Any suggested mitigations.

---

## 🏛️ Vulnerability Handling & Response

Once a report is received:
1. **Verification**: We will verify the vulnerability and its potential impact.
2. **Resolution**: We will work on a fix as quickly as possible.
3. **Disclosure**: Once a fix is deployed, we will coordinate public disclosure if appropriate.

---

## 🤝 Responsible Disclosure Guidelines

- **Privacy**: Please give us a reasonable amount of time to resolve the issue before any public disclosure.
- **Ethics**: Avoid any actions that may impact the stability of the production Discord bot or compromise personal user data.
- **Compliance**: We will not take legal action against researchers who discover and report vulnerabilities in compliance with this policy.

*Thank you for helping keep the Hive safe! 🐝*
